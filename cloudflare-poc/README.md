# Phase 1 local-only feasibility harness

**Not a production API.** Never deploy this config, connect the official phone app, enter real personal data, or attach remote resources. No production /api routes, sessions or owner accounts implemented. Existing cloudflare/ is upstream failover and must not be touched.

Run from repo root with Node 26 (upstream CI version):
```sh
cd cloudflare-poc
npm install --no-audit --no-fund
npm test
```
The runtime test starts Wrangler dev with --local, loopback and a disposable persistence directory; shuts down and restarts the same local disk, cleans up. No credentials required. The unit tests need no dependencies (`node --test test/state.test.mjs`). The synthetic P-256 authenticator exercises SimpleWebAuthn registration and signed login including negative challenge/replay; does not prove actual browser or mobile compatibility. The Node adapter tests body, method, URL, headers and multiple cookies, not the original monolithic server. DO transaction test uses 512 KiB chunks to avoid dependence on recent 8 MB SQL row support. The experiment is deliberately stricter about baseRev/baseWid than upstream; production parity is Phase 2. No real auth/security claims for /__poc routes. 
Local timing is wall time, not hosted CPU. The thin Worker only forwards heavy operations to DO. Real hosted Free-tier CPU/memory, real-browser WebAuthn, and shared account quota remain unverified. Never reduce security or truncate state to fit budget.

Frontend build/manifest (from repo root):
```sh
(cd frontend && npm ci --ignore-scripts --no-audit --no-fund && npm run build)
node scripts/catalogue/stage-media.mjs frontend/dist
(cd cloudflare-poc && npm run assets)
```
No media is copied outside openGym. Manifest checks Free limits (20k assets, 25 MiB per file), not actual deployment. 
Pinned direct dependencies; lockfile not yet generated because npm network is unavailable in authoring runtime. CI installs exact direct versions and generates local lock; commit verified lockfile before Phase 2. No deploy commands in workflow.

The HTTP adapter is now an isolated worker/config (`wrangler.node.jsonc`) with its own test process, so adapter failure does not prevent the Fetch/DO tests running. CI publishes the generated lockfile and asset manifest as short-lived artifacts. Neither configuration is deployable by project policy.

Test files run sequentially to avoid Wrangler internal direct-socket port contention. CI concurrency is per commit, so follow-up validation does not cancel older regression jobs. If the lockfile is present, CI uses npm ci. The temporary lockfile evidence script only emits a checked public npm dependency lock and is removed after it is tracked.

## Phase 2 local storage
`wrangler.storage.jsonc` is a separate disposable test harness, not a deployable server. Install locked dependencies in api/, frontend/ and cloudflare-poc/ with npm ci, then run `cd cloudflare-poc && bash test/profile-local.sh`. GNU time reports aggregate process CPU and peak RSS; DO wall times and SQL counters are logged separately. No production API or real profile data. See docs/cloudflare-migration/phases/PHASE_02.md.

## Phase 3 local authenticated API (candidate)
`wrangler.api.jsonc` is **not a production configuration**. CI uses fresh random synthetic secrets passed to local Wrangler and disposable persistence directories. No auth fixture/debug routes in this API. Run from repo root after `npm ci` in api/ and cloudflare-poc/; then `cd cloudflare-poc && node --test --test-concurrency=1 test/auth-core.test.mjs test/auth-fault.test.mjs test/auth-differential.test.mjs test/auth-browser.test.mjs`. Requires Node 26 and Chrome (or CHROME_BIN). Browser test uses CDP virtual authenticator, not a physical passkey. See PHASE_03.md for acceptance state. For a manual test, use a dedicated disposable local profile and unique local test secrets in ignored .dev.vars, API_ORIGIN matching localhost port, RP_ID=localhost, loopback only. Never enter real workout/account data or reuse production secrets. Do not deploy. Manual physical passkey acceptance is still open; instructions to be finalized during review.
